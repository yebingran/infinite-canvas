# 待测试

- 管理后台渠道新增「算力萌视频」协议；`/models` 连接测试不提交生成任务。视频代理把时长、比例、分辨率和首尾帧转换为算力萌 `/v1/videos` 字段，使用创建响应中的 `vid_...` ID 轮询 `/v1/videos/{id}`，并将进行中及 7 天内完成的任务同步到账号历史；请人工验证文生、首尾帧图生、刷新页面后的任务恢复及完成后的 MP4 显示。
- 画布视频：生成接口返回成功地址后立即展示，OSS 自动同步完成后再更新存储地址；请使用新加坡 OSS 验证同步期间可播放、同步后刷新仍可播放。
- 视频同步：从已下载的视频读取尺寸，避免上传后再次远程读取；尺寸读取最多等待 10 秒。
- 视频提交：提示词首行明确指定的比例或分辨率与视频设置冲突时，提交前提示，不发送生成请求。请验证 9:16、1080P 提示词配合 1:1、720P 设置会被拦截，统一设置后正常提交。
- 算力萌 H3：比例使用 `ratio`，显式传递 `t2v` / `i2v`；画布可选择首尾帧，尾帧不再丢失，首帧不再混入普通图片列表。多张独立人物/场景参考在提交前拦截，避免上游将其按时间轴生成转场；单图按首帧处理。请验证文生、单首帧、首尾帧请求和多参考图拦截。
- 镜像：`comemoe-video-adapter` 分支推送后构建同名镜像标签及提交 SHA 标签，供 1Panel 拉取更新。
