# 待测试

- 系统设置的公开配置新增「站点滚动公告」：可启停、增删、排序并编辑文字和可选链接；前台从公开设置读取并轮播，公告内容改变后曾关闭公告的浏览器会再次显示。请人工验证保存、刷新、无公告、停用以及跨设备显示。
- 管理后台渠道新增「算力萌视频」协议；`/models` 连接测试不提交生成任务。视频代理把时长、比例、分辨率和图片参考转换为算力萌 `/v1/videos` 字段，使用创建响应中的 `vid_...` ID 轮询 `/v1/videos/{id}`，并将进行中及 7 天内完成的任务同步到账号历史；请人工验证文生、单图生、多图生、刷新页面后的任务恢复及完成后的 MP4 显示。
- 管理后台新增 New API（OpenAI 兼容）渠道，默认 Base URL 为 `https://ai.yunsuguan.com/v1`；OpenAI 图片响应与 Gemini `inlineData` / `inline_data` 响应增加多种媒体字段解析，后端中断超过 2 分钟的图片任务会标记失败并允许重试。请用云速管实际可用的 GPT Image 2 与 Gemini 图片模型验证模型列表、聊天、生图、编辑、刷新恢复和超时/服务重启后的失败提示；云速管公开文档未确认图片或 Gemini 原生端点是否开放。
